### 01 · About

I'm a research scholar at **IIT Ropar** (AI & Data Engineering), working on **domain adaptation and transfer learning**: how to keep a model useful when the data it meets in deployment doesn't look like the data it was trained on. Most of my current work is unsupervised and partial domain adaptation, built on prototypical contrastive learning and optimal transport, across plant-disease imagery and remote-sensing data.

Before the PhD I spent my time on applied ML. At C-DAC Mohali I built a reinforcement-learning SSH honeypot and fine-tuned a small language model for command generation; outside of that I shipped a few vision projects, which you'll find below.

### 04 · Selected projects

#### [AI Clinical Skin Disease Detection](https://github.com/itsluckysharma01/Skin_Diseases_Detection_Using_Deep-Learning_30_Classes)
`EfficientNet` `Python` `Flask` `Docker` `Hugging Face Spaces`

A 30-class skin-condition classifier trained on 6.4K images. It reaches 91% training and 75% validation accuracy, and runs as a browser-based app on Hugging Face Spaces, so nobody has to install anything to try it.

[Repository](https://github.com/itsluckysharma01/Skin_Diseases_Detection_Using_Deep-Learning_30_Classes) · [Live demo ↗](https://huggingface.co/spaces/itsluckysharma01/Skin_Diseases_Detection_of_30_Classes)

#### [NETRA — Smart Video Surveillance](https://github.com/itsluckysharma01/NETRA-Network-for-Enhanced-Threat-Recognition-Action-)
`YOLOv8` `OpenCV` `Flask` `Python`

Network for Enhanced Threat Recognition & Action. YOLOv8-based video analysis that flags threats in real time (98% detection accuracy) and triggers response actions automatically instead of waiting on someone watching the feed.

[Repository](https://github.com/itsluckysharma01/NETRA-Network-for-Enhanced-Threat-Recognition-Action-) · [Live demo ↗](https://huggingface.co/spaces/itsluckysharma01/NETRA-A_Video_Surveillance_Web_Application)

#### [Museum Heist — Pursuit-Evasion under Partial Observability](https://github.com/itsluckysharma01/The-Museum-Heist-Pursuit-Evasion-Simulation_-Cat-and-Mouse-_POMDP-CDAC)
`POMDP` `BFS` `Pygame` `Python`

A cat-and-mouse simulation on a 10×10 grid. The guard tracks a hidden intruder with a noisy POMDP belief state and live heatmaps; the intruder switches between four behaviour modes depending on how close the threat is.

[Repository](https://github.com/itsluckysharma01/The-Museum-Heist-Pursuit-Evasion-Simulation_-Cat-and-Mouse-_POMDP-CDAC)
